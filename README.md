# coral
A composable CRDT library for collaborative applications.

## Acknowledgments

Coral's core CRDT architecture is inspired by [Loro](https://github.com/loro-dev/loro), including CausalGraph, Heads, VersionVector, Op/Commit, and related primitives. Coral is an independent, simplified implementation focused on learning and exploring CRDT internals. Loro is licensed under the [MIT License](https://github.com/loro-dev/loro/blob/main/LICENSE).
